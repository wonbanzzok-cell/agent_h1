# PPT 규칙 (v1)

이 프로젝트에서 PowerPoint(`.pptx`) 덱을 만들거나 수정할 때 항상 이 규칙을 따른다. `mk-ppt` 스킬과 함께 적용된다.

## 0. 우선순위

- `mk-ppt` 스킬이나 다른 슬라이드 스킬보다 이 규칙을 먼저 적용한다.
- 내용이 서로 다르면 **이 규칙 파일 → 사용자의 디자인 파일 → `mk-ppt` 스킬** 순서로 따른다.
- 디자인 파일은 더 엄격한 값을 정할 수는 있지만, 여기 있는 최솟값(글자 크기, 여백, 간격)을 낮출 수는 없다.
- `.pptx` 작업에는 전역 `pptx` 스킬이 아니라 이 프로젝트의 `mk-ppt` 스킬을 쓴다.

## 1. 기본 슬라이드 수: 8장

- 기본으로 8장을 만든다. 표지와 마무리 슬라이드도 장수에 포함한다.
- 사용자가 다른 장수를 요청하면 그 장수를 따른다.
- 내용이 8장에 다 들어가지 않으면 억지로 채워 넣지 않는다. 사용자에게 알리고, 슬라이드를 나누거나 내용을 줄이자고 제안한다.

## 2. 사용자의 디자인 파일을 따른다

- 만들기 전에 사용자가 준 디자인 `.md` 파일(색상, 폰트, 레이아웃, 여백, 톤 등)을 읽는다.
- 파일 내용을 모든 슬라이드에 적용한다. 파일에 없는 부분은 그 스타일에 맞는 기본값을 쓴다.
- 디자인 파일을 받지 못했으면 만들기 전에 사용자에게 요청한다. 사용자가 파일 없이 진행하라고 할 때만 프로젝트 기본값을 쓴다.
- 최종 보고에는 적용한 디자인 규칙과, 따르지 않은 부분 및 그 이유를 적는다.

## 3. 넘침과 겹침 금지

텍스트가 슬라이드 밖으로 넘어가면 안 되고, 텍스트나 도형이 서로 겹쳐 가독성을 해치면 안 된다.

- **텍스트 양 제한.** 슬라이드 한 장에 글머리표는 6개 정도, 글머리표 하나는 2줄 정도로 한다. 넘치는 내용은 다른 슬라이드나 발표자 노트로 옮긴다.
- **텍스트에 맞는 상자 크기.** 모든 글상자는 정한 폰트 크기에서 텍스트가 다 들어갈 만큼 크게 만들고, 자동 줄바꿈을 켠다. 그래도 넘치면 폰트를 줄이기 전에 문장을 줄이거나 슬라이드를 나눈다. 본문은 14pt, 제목은 24pt 밑으로 줄이지 않는다.
- **여백과 간격 확보.** 모든 요소는 슬라이드 가장자리에서 0.4in(약 1cm) 이상 떨어뜨리고, 요소끼리는 0.2in 이상 띄운다.
- **그리드로 레이아웃 계획.** 요소를 배치하기 전에 각 요소의 위치와 크기를 정해, 제목·본문·이미지·차트·도형이 각자 영역을 갖게 한다.
- **만든 뒤 검사.** python-pptx로 덱을 다시 읽어 다음을 확인한다:
  - 모든 도형이 슬라이드 안에 있는지 (`left >= 0`, `top >= 0`, `left + width <= slide_width`, `top + height <= slide_height`)
  - 두 도형의 경계 상자가 겹치지 않는지 (의도한 배경이나 도형 위에 올린 글상자는 예외)
  - 각 상자의 텍스트가 상자 높이보다 많은 줄을 차지할 가능성이 없는지 (글자 수, 폰트 크기, 상자 너비로 추정)
- 문제를 찾으면 고치고 다시 검사한다. 렌더링된 슬라이드를 직접 볼 수 없으므로 보고할 때 그 점을 밝히고, 사용자에게 PowerPoint에서 파일을 열어 확인해 달라고 요청한다.
