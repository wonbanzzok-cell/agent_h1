# 슬라이드 디자인 시스템 — 오렌지 비즈니스

`.pptx` 덱을 만들 때 참고하는 디자인 문서로, "PPT PRESENTATION" 오렌지 템플릿 이미지를 기준으로 했다. `.claude/rules/ppt-rule-v1/ppt-rule-v1.md`와 함께 쓴다. 두 문서가 다르면 규칙 파일의 최소 기준을 따른다.

아래 색상과 폰트는 이미지에서 추정한 값이므로 근사값으로 본다.

## 1. 톤

- 깔끔하고 현대적인 비즈니스 톤. 슬라이드 대부분은 흰색이고, 포인트 색은 오렌지 하나만 쓴다.
- 여백을 넉넉히 둔다. 데이터는 빽빽한 텍스트 대신 원, 링, 막대로 보여 준다.

## 2. 색상 (근사값)

| 역할 | HEX | 용도 |
|------|-----|------|
| 메인 오렌지 | `#F26522` | 포인트 도형, 아이콘, 링, 강조 행, 라벨 |
| 연한 오렌지 | `#F7A27A` | 보조 링 구간, 차트 채우기 |
| 아주 연한 오렌지 | `#FDE3D6` | 은은한 배경, 링 트랙 |
| 레드 오렌지 | `#E8432B` | 두 번째 막대 계열, 강조 텍스트(드물게) |
| 블랙 | `#1A1A1A` | 제목, 헤더 텍스트, 검은 필 |
| 진회색 | `#444444` | 본문 |
| 중간 회색 | `#9A9A9A` | 캡션, 보조 텍스트 |
| 연회색 | `#EDEDED` | 구분선, 링 트랙, 노트 상자 |
| 흰색 | `#FFFFFF` | 슬라이드 배경 |

- 오렌지는 슬라이드 면적의 10~20% 정도로만 쓴다. 다른 색은 더하지 않는다.

## 3. 폰트

| 요소 | 폰트 | 스타일 | 크기 |
|------|------|--------|------|
| 표지 제목 | Montserrat (대체: Arial Black) | Extra Bold Italic, 검정 | 54–60 pt |
| 슬라이드 헤더 제목 | Montserrat (대체: Arial) | Bold Italic, 검정 | 24–28 pt |
| 섹션 라벨("CONTENTS A") | 맑은 고딕 | Bold, 검정 또는 오렌지 | 16–18 pt |
| 본문(한글) | 맑은 고딕 | Regular, 진회색 | 14–16 pt |
| 캡션 | 맑은 고딕 | Regular, 중간 회색 | 14 pt |
| 큰 숫자("75%") | Montserrat (대체: Arial) | Bold, 검정 | 28–40 pt |

- 라벨(CONTENTS, TEXT A)은 영문 대문자로 쓰고, 한글은 본문에 쓴다.
- 템플릿의 캡션은 14pt보다 작다. ppt-rule-v1에 따라 14pt 이상으로 유지한다.

## 4. 캔버스와 그리드

- 16:9, 13.333 × 7.5 in. 배경은 흰색.
- 여백: 사방 0.5 in. 요소 간격: 0.2 in 이상.
- 콘텐츠 영역: 헤더 아래(top ≈ 1.2 in)부터 7.0 in까지.
- 콘텐츠 슬라이드는 대부분 3열 그리드를 쓴다(열 ≈ 3.8 in, 거터 ≈ 0.4 in).

## 5. 공통 헤더 (모든 콘텐츠 슬라이드)

- **왼쪽 위:** 작은 오렌지 탭(≈1.3 × 0.35 in)을 둔다. 오른쪽 끝은 둥글거나 사선이고, 안에 흰색 "CONTENTS"를 쓴다. 바로 옆에 이탤릭 볼드 슬라이드 제목을 둔다.
- **얇은 회색 선**(`#EDEDED`, 0.75 pt)을 제목에서 오른쪽 여백까지 긋는다.
- **오른쪽 위:** 작은 검은 필(≈0.9 × 0.25 in)에 흰색 라벨(페이지 또는 섹션)을 넣는다.
- **아래쪽:** 얇은 오렌지 선(1 pt)을 여백 안쪽으로 가로질러 긋는다.

## 6. 슬라이드 레이아웃

| 레이아웃 | 설명 |
|----------|------|
| 표지 | 왼쪽에 넓은 오렌지 캡슐(오른쪽 끝이 둥긂)을 두고, 그 안에 오렌지 오버레이(약 70% 불투명)를 씌운 사진과 흰색 헤드라인을 넣는다. 오른쪽에는 검정 볼드 이탤릭 제목과 그 아래 회색 부제를 둔다. 배경에는 옅은 오렌지 사선과 얇은 회색 동심원을 깐다. 왼쪽 아래에 작은 필 두 개(오렌지, 검정)를 둔다. |
| 3열 아이콘 원형 | 원 세 개를 가로로 놓는다. 각 원은 오렌지 부분 링, 흰색 중심, 오렌지 아이콘으로 이루어진다. 작은 오렌지 삼각형이 아래의 라벨과 짧은 설명을 가리킨다. |
| 3열 도넛 | 도넛 차트 세 개(오렌지, 연한 오렌지, 아주 연한 구간)를 놓는다. 각각 위에 오렌지 아이콘 배지, 가운데에 "CONTENTS", 아래에 텍스트를 둔다. |
| 이미지 + 리스트 | 오른쪽에 큰 원형 사진(흑백)을 두고 그 호를 따라 오렌지 아이콘 원을 배치한다. 그 왼쪽에 라벨 + 텍스트 항목 3개를 둔다. 맨 왼쪽에는 강조 카드 하나를 둔다. |
| 퍼센트 링 | 얇은 오렌지 호 세 개 안에 큰 % 숫자를 넣고, 얇은 회색 선으로 아래 라벨과 잇는다. 아래쪽에는 오렌지 "Check" 태그가 달린 회색 노트 상자를 둔다. |
| 표 | 3열(라벨, 텍스트, 점 평가). 행 사이에 얇은 회색 구분선을 긋는다. 강조 행 하나는 오렌지 채우기에 흰 글씨로 한다. 오른쪽 아래에 오렌지 필 버튼을 둔다. |
| 막대 비교 | 두 그룹으로 나눈다. 각 그룹은 라벨이 붙은 괄호선과 % 값이 붙은 가로 막대 두 개(오렌지, 레드 오렌지)로 이루어진다. 검은 원 "Check" 표시가 두 그룹을 잇는다. |

## 7. 도형과 그래픽

- 도형: 원, 링이나 호, 캡슐(완전히 둥근 사각형), 필 라벨. 표 말고는 각진 상자를 피한다.
- 선: 얇게(0.75–1 pt), 회색이나 오렌지로.
- 아이콘: 단순한 플랫 선형 또는 채운 글리프. 오렌지 원 위에 흰색, 또는 흰 바탕 위에 오렌지.
- 사진: 흑백이거나 오렌지 오버레이를 씌운다. 원이나 캡슐 모양으로 자른다.
- 그림자: 없거나 아주 옅게. 옅은 배경 장식 말고는 그라데이션을 쓰지 않는다.

## 8. 할 것 / 하지 말 것

- **할 것:** 포인트 색은 하나만 쓰고, 그리드에 맞춰 정렬하고, 모든 콘텐츠 슬라이드에 같은 헤더를 반복하고, 한 줄에는 항목을 3개까지만 둔다.
- **하지 말 것:** 글머리표 6개 정도를 넘기기, 다른 밝은 색 더하기, 14pt 밑으로 줄이기, 장식이 텍스트와 겹치게 두기.
